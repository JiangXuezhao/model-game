# 小小架构师 · Transformer 搬运工厂 5.1

现在首页是一个可用键盘控制角色的俯视角搬运游戏。走进 Transformer 工厂，把零件从货架搬到机位，亲手拉线，再去电闸启动机器。

## 开始游玩

```sh
npm start
# 或 PORT=4175 node server.cjs
```

- **WASD / 方向键**：走动，不能穿过机位或货架。
- **Shift**：快走。
- **E**：走近货架拿零件；拿着零件到空机位安装；空手在机器旁拉起输出线；搬线头到目标后选择输入。
- **1 / 2 / 3**：接线时选择输入端口。
- **Q**：拿着零件时放地上，E 可以捡回；空手在模块旁拆下零件及相关线路；拿着线头时取消。
- **I**：在货架或模块旁查看原理；模块输入线可在检查弹窗中拔下。
- **Esc**：暂停 / 返回。暂停菜单提供撤销上一次装配。

手机使用屏幕方向键和 E / Q / I。方向键可持续按住，离开页面会清除按键，避免角色一直走。

### 学徒与建造师

**学徒模式**：从半成品开始，搬回缺件。普通主线在安装时自动接入，但残差旁路和跨塔 K/V 等关键分支需要走过去拉线。

**建造师模式**：空机位、空线路。全部零件与线缆都由角色搬运组装。

两种玩法分别保存。六间车间对应经典双塔、三种 Attention 内部、FFN 与残差、Decoder-only。工厂布局保留经典架构的分支与层次，不是随机把模块散在地上。

角色接近目标才可以操作；零件举在头顶，输出线会跟随角色。归还台回收不需要的物品，地上零件可拾回。取下模块会断开它的相关线路。每次错误是调试线索，没有倒计时或失败扣分。

走到黄黑总电闸按 E，调用真实小矩阵执行器。放齐零件不等于通关，还需运算类型、输入来源、张量形状与完整线路正确。

### 保存与边界

`transformer-factory-v1` 保存角色位置、手持物品、地面零件、已装机器、接线与通关徽章。新游戏不覆盖原来的架构图和实验成绩；刷新停止正在执行的试跑。

物理布局展开一层、二维俯视、小规模手工参数；没有训练或调用真实语言模型，也不执行真实业务操作。

## 核心玩法

1. 从零件盒拿一块，点击槽位放入；桌面也可拖入。选择零件时会聚焦待装位置。
2. 点模块上方的 OUT，再点目标下方的输入端口。一个输出可以连多路；一个输入只接一个来源，新连接会替换旧连接。
3. 残差旁路、跨塔线路与普通主线不同。尺寸相同不代表来源正确。
4. 点击模块进入检查台，查看公式、输入来源、预期形状。通电后可以看每个输入和输出的真实张量。
5. 通电时按依赖顺序计算；缺件、断线、矩阵形状、环路、运算类型或来源错误都会阻止交付。
6. 点线可拔线，也可以在检查台断开某个输入、移除模块。撤销会恢复上一步。
7. 使用可读视图、全图、缩放与小地图定位。空白画布可拖动平移；手机使用滑动、点选零件和端口。

运行可停止。刷新保存组装与成绩，但停止正在运行的计算；中间张量不持久保存，需要重新通电。

## 挑战方式

- **补全挑战**：从半成品开始，补关键零件与断线。
- **从零组装**：空槽位与空线路；架构布局是脚手架，每一块和每条线都由玩家搭建。
- **成品拆解**：完整电路供检查和实验；运行可验证，但不计通关。

三种方式各自保存装配状态。线路草图可关闭。重置仅影响当前电路、当前方式；保留成绩并支持撤销重置。

## 六张电路

### 经典 Transformer 双塔

- Token Embedding、√d_model 缩放、正弦位置编码与相加。
- Encoder 自注意力、残差 Add、LayerNorm、FFN、第二次 Add & Norm。
- 右移目标输入；Decoder 的因果自注意力、Cross-Attention、FFN 和三组 Add & Norm。
- Encoder 最终输出送入 Cross-Attention 的 K/V；Q 来自 Decoder 上一子层。
- 词表投影与 Softmax。

### 三种 Attention 内部

每个头分别拼出 Q/K/V 投影、QKᵀ、÷√d_k、Softmax、×V，再拼接两个头并执行 W_O：

- **Encoder**：自注意力，无因果遮罩。
- **Decoder**：自注意力，在 Softmax 前将未来分数设为 −∞。
- **Cross**：两路输入，Decoder 提供 Q，Encoder 提供 K/V，无三角因果遮罩。

### FFN 与残差

4→8 线性层 → ReLU → 8→4 线性层 → 与原始输入相加 → LayerNorm。

### Decoder-only 对照分支

GPT 式教学分支：可学习绝对位置表、Pre-LN、因果注意力、GELU 前馈、两条残差与最终 LayerNorm。不是把经典双塔简单删除 Encoder 的结果。

## 实际计算与教学边界

依据经典论文 *Attention Is All You Need*（2017）：https://arxiv.org/abs/1706.03762 。

经典双塔展开 1 层 Encoder 和 1 层 Decoder，而非原论文的各 6 层。d_model=4、heads=2、d_k=2、d_ff=8，序列长度为 3。输入词表、权重、偏置均为确定的教学值；LayerNorm γ=1、β=0，不启用推理时 Dropout。小矩阵计算真实执行，但不是已训练的翻译模型。

数值包括查表、sin/cos 位置编码、投影、QKᵀ、缩放、Mask、逐行 Softmax、加权 V、Concat、W_O、FFN、残差、LayerNorm 和词表投影。Attention 子电路的结果已与主架构使用的对应计算函数对照。内部独立电路使用固定示例输入，不自动复用总装页的运行状态。

本版本在固定架构槽位中组装，尚不支持任意增删层数或自由移动模块。完整多层训练、反向传播、优化器、KV cache 和真实模型推理未在主拼装画布实现；原理实验室保留相关小实验。

## 4.1 问题修正

- 停止运行只保留已播放完成步骤的张量，不再提前显示后续模块结果；改动线路后清除旧运行标记。

- Add 的 A/B 两路可以交换，仍需保留两种正确来源；Concat、Q/K/V 等非交换运算保持端口语义。
- 小地图按 SVG 的真实变换定位，修复宽高比例导致的点击偏移。
- 默认可读视图提高显示比例、加大模块文字；全图用于概览，放大用于操作。
- 增加跟随信号开关；手动拖动画布会取消自动跟随。
- 非法端口、重复输入连接提供明确错误。
